# Shared frozen Veda contract (sc-25770)

`gen_core::veda::contract` is the tensor-neutral authority used by MLX and
Candle native packed layouts. It holds the complete twelve-plan, 50-layer,
56-head table captured from the frozen predictor header. Production loading
requires the E7 artifact byte count and SHA256, matching dimensions and the
entire table. Fixture loading through `Bundle::from_meta` remains possible for
small weights-free native tests and validates every declared projection, dtype,
scale, plan row and tensor key; it never supplies a missing field or projection.

Reference spans are retained at their original native boundaries, including
intervening soundtrack/audio rows. Only references whose exact positions prove
T/H/W row-major order are tiled; other rows stay global. References use the
frozen least-padding shape. Every tile compacts real rows to a valid prefix,
keeps the frozen h-block/w-block/t-block ordering, and places globals last.

`PredictorOps` is an associated-type arithmetic seam, with no tensor dependency.
The shared scoring driver owns BF16-decoded projection lookup, mean residual
addition and division by the square root of the head dimension. MLX supplies
pool/matmul/slice/add/dot primitives. The CPU pooling/logit oracle and captured
on-device MLX mask fixture test the same driver. CUDA's implementation consumes
this seam and shared layouts/selection in its kernel story; a CPU gate cannot
establish CUDA execution or device-mask parity.

Selection accepts independent reference/generated `Budget::Ratio` or
`Budget::Tiles` values. Equal-cost token-based ratios, forced budget-consuming
diagonals, twelve-decimal fractional allocation and global dense rows follow the
frozen implementation. The ascending tile-ID rows returned to both kernels are
the block mask; they are not an independently reranked selection.

## Numerical authority and capture

The source authority is Veda-on-ComfyUI revision
`60bfae688897dc41bc8685ca9f3130d7ed8f3b0c`. The retained fixture
`crates/contracts/gen-core/tests/fixtures/veda/frozen.json` records source file
SHA256 values, the exact predictor-header SHA256, Python package versions,
input/projection/score dtypes and CPU identity. Expected masks are captured by
calling frozen `tiling`, `plans`, `predictor` and `selection` Python functions;
they are not generated by the Rust port.

Reproduce the fixture in a CPU environment with `torch==2.14.1` and
`safetensors==0.8.0`, supplying the retained source snapshot and predictor header:

```sh
python scripts/fixtures/capture_veda.py \
  --source /path/to/frozen/60bfae6 \
  --header /path/to/hf-safetensors-header.json \
  --out crates/contracts/gen-core/tests/fixtures/veda/frozen.json
```

The capture exercises all twelve exact/transposed plans plus nearest aspect,
duration and padding choices; four permutation layouts; separate budgets;
partial/global rows; ties and near ties; 850 randomized tied top-k cutoff probes;
and three complete BF16-input/FP8-projection/TripPool/logit/mask cases. Floating
logit comparisons help diagnose arithmetic; **selected-mask equality is exact**.

Frozen `torch.topk` does not define a universal tie order across device kernels
or standard-library implementations. The shared port explicitly preserves the
captured CPU libc++ partition/heap cutoff ordering on every backend, including
fractional rows. It does not replace tied scores with an ascending-ID sort.
LLVM-derived partition code carries `LICENSE.llvm`; frozen Veda adaptations
carry `LICENSE.upstream`.

## Empty-key edge

A positive-grid tiling never creates an empty video tile. A synthetic empty video
tile exposes a frozen-source edge: the own-diagonal scatter overwrites its
`-inf` empty-key score with `+inf`. E2 explicitly requires exclusion of empty
keys. The retained fixture therefore stores both untouched `upstream_rows` and
E2 `rows` with only empty keys excluded. Ordinary cases assert exact equality
to untouched upstream rows; synthetic empty cases assert the separate E2
exclusion. The empty diagonal still consumes its budget, preserving the frozen
allocation and other chosen keys. This is a disclosed edge, not an assertion
that differing masks are equal.

## Local/device gate boundary

CPU suites verify the frozen masks, strict metadata, tensor-neutral contract,
and Candle native reference mapping without weights or accelerators. The ignored
MLX `frozen_upstream_device_scores_select_exact_masks` test requires coordinator
Metal admission. Native kernel self-tests and real-weight media acceptance are
separate gates, owned by their kernel and terminal stories. No output tolerance,
CPU compile check or shared-function identity certifies an unexecuted device
mask test.

The CUDA descriptor also belongs to the shared `candle_quant_kernels::NVRTC_SOURCES`
registry. Its workspace-wide CPU guard lives in `candle-llm`, so a provider-only
test run does not check that registration. After adding or changing a kernel
descriptor, run `cargo test --locked -p candle-llm --lib nvrtc_source_tests` as
well as its owning package tests. The existing CUDA all-kernels check then covers
Veda's entry points; registry success alone does not establish device compilation
or zero-local-memory acceptance.
